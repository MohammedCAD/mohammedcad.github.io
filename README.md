# Mechanical Engineering Portfolio

Static GitHub Pages portfolio. Open `index.html` locally or publish this folder as the GitHub Pages site root. All CAD photographs are sourced from the supplied portfolio PDF.

## Publication

Create a new public GitHub repository for this web portfolio only; do not upload private CAD assemblies, personal CV source files, or internal development repositories. Upload `index.html`, `styles.css`, `cad/`, and `assets/`. Enable GitHub Pages from the main branch root.

Descriptions use the provided CAD screenshots and project documentation. Feature lists reflect modelling workflows and geometry, not independently audited feature histories. Confirm public-image sharing rights and the contact email before deployment.
